# AI剧本撰写流程 Skill

> 从选题到分镜的完整AI微短剧剧本撰写工作流

## 📖 简介

本skill提供6个标准化步骤，帮助用户从0到1完成一部微短剧的完整剧本撰写工作。每步都有标准化的提示词模板、输出格式和真实示例。

## 🎯 适用场景

- 微短剧（竖屏、1-3分钟/集、抖音/快手/红果短剧）
- 中视频短剧（横屏、5-10分钟/集、平台定制剧）
- AI漫剧（先有剧本再生成视频）
- 短视频剧本（剧情号、品牌故事）

## 🚀 快速开始

### 方式1：从头开始

直接告诉AI：
> "帮我做一个AI剧本"

AI将自动进入第1步（选题赛道分析）。

### 方式2：指定步骤

直接告诉AI：
> "第3步：写剧本"
> "帮我设计故事大纲"
> "出分镜脚本"

AI会跳转到对应步骤。

### 方式3：使用指令集

| 指令 | 说明 |
|------|------|
| `~start` | 从第1步开始 |
| `~step N` | 跳转到第N步（1-6） |
| `~help` | 显示所有可用指令 |
| `~example` | 显示完整示例 |
| `~template [N]` | 显示第N步的输出模板 |

## 🔄 6步工作流

### 第1步：选题赛道分析
- **目的**：分析微短剧市场最热门的5大赛道，推荐1个最适合新手的赛道
- **输入**：无（或用户指定的赛道偏好）
- **输出**：5大赛道分析 + 推荐赛道 + 平台适配建议
- **示例**：`examples/婆婆您配吗/step1-topic.md`

### 第2步：故事大纲设计
- **目的**：基于第1步的赛道，设计完整的20集故事大纲
- **输入**：赛道 + 集数 + 平台 + 受众
- **输出**：核心设定 + 人物设定 + 20集分集大纲 + 节奏设计 + 续集空间
- **示例**：`examples/婆婆您配吗/step2-outline.md`

### 第3步：单集剧本撰写
- **目的**：将分集大纲转化为标准剧本格式
- **输入**：故事大纲 + 本集大纲 + 上一集结尾（如适用）
- **输出**：场景+对话+动作指示的标准剧本
- **示例**：`examples/婆婆您配吗/step3-script.md`

### 第4步：钩子优化
- **目的**：优化剧本的开头（前5秒）和结尾（后5秒）
- **输入**：单集剧本
- **输出**：开头3版本 + 结尾3版本 + 平台适配组合
- **示例**：`examples/婆婆您配吗/step4-hook.md`

### 第5步：自我审查
- **目的**：作为内容审核编辑评估剧本
- **输入**：完整大纲或剧本
- **输出**：4维度评分 + 优先修改的3个问题
- **示例**：`examples/婆婆您配吗/step5-review.md`

### 第6步：AI分镜脚本撰写
- **目的**：将剧本转化为专业分镜脚本
- **输入**：剧本 + 平台 + 设备 + 风格
- **输出**：完整分镜 + 拍摄清单 + 后期指引
- **示例**：`examples/婆婆您配吗/step6-storyboard.md`

## 💡 核心特性

### 1. 每步独立可执行
- 每步都有独立的提示词模板
- 用户可以从任意步骤开始

### 2. 标准化的输出格式
- 每步都有明确的输出模板
- 关键信息用表格+清单组织

### 3. 平台导向的差异化建议
- 抖音、快手、红果短剧各有适配版本

### 4. 审核安全内嵌
- 第5步内置"审核风险评估"环节

### 5. 配套真实示例
- 完整《婆婆，您配吗》示例可作为标杆

## 📚 完整示例项目：《婆婆，您配吗》
