# AI剧本撰写流程 Skill

## 核心定位

**输入**：用户从6个步骤的任意一步开始（默认从第一步开始）
**输出**：可直接投入拍摄筹备的完整短剧剧本+分镜
**特色**：每步都有标准化提示词+输出模板+真实示例，可逐环节交付

**适用场景**：
- 微短剧（竖屏、1-3分钟/集、抖音/快手/红果短剧）
- 中视频短剧（横屏、5-10分钟/集、平台定制剧）
- AI漫剧（先有剧本再生成视频）

## 详细工作流程

### 第1步：选题赛道分析

**目的**：分析当前微短剧市场最热门的5大赛道，推荐1个最适合新手的赛道。

**触发条件**：
- 用户说"开始第一步"、"~start"
- 用户说"帮我选个赛道"
- 用户首次进入skill未指定步骤

**标准提示词模板**（位于 `prompts/step1-topic.md`）：

```
你是一个资深的微短剧策划，在抖音和快手做了3年短剧内容，经手过多部播放量破亿的项目。
请帮我分析当前微短剧市场最热门的5个赛道。

要求：
1. 每个赛道给出：
   - 赛道名称和核心吸引力（为什么观众爱看）
   - 典型爆款案例1-2个（剧名+大致剧情）
   - 目标受众画像（性别、年龄、看剧场景）
   - 当前竞争程度（红海/蓝海/中等）
   - 适合新手入场的程度（1-5分）

2. 在5个赛道中，推荐1个最适合新手的赛道，理由要具体

3. 补充说明：当前平台（抖音/快手/红果短剧）各自偏好什么类型的内容？审核红线在哪？
```

**输出模板**（位于 `templates/step1-output.md`）：

| 部分 | 内容 | 字数建议 |
|------|------|---------|
| 一 | 5大赛道分析 | 1500-2000字 |
| 二 | 新手推荐赛道+理由 | 300-500字 |
| 三 | 平台偏好与审核红线 | 300-500字 |

**完成后自动引导**：
> ✅ 第一步完成！请告诉我第二步是否继续（基于「XX赛道」，撰写20集故事大纲）。
> 输入 `~step 2` 直接进入第二步。

---

### 第2步：故事大纲设计

**目的**：基于第1步确定的赛道，设计完整的20集故事大纲。

**标准提示词模板**（位于 `prompts/step2-outline.md`）：

```
我要做一部微短剧，基本信息如下：

【赛道】[填第1步选的赛道]
【集数】[填总集数，比如：20集，每集1-2分钟]
【目标平台】[填平台，比如：抖音短剧]
【目标受众】[填受众，比如：25-40岁女性，下班后刷剧解压]

请帮我设计一个完整的故事大纲，要求：

1. 核心设定：
   - 一句话概括这个故事（不超过30字）
   - 主角是谁？TA的初始处境是什么？（要够惨或够不甘）
   - 核心反转是什么？（从什么变成什么）
   - 爽点在哪里？（观众看到什么时候会觉得"过瘾"）

2. 人物设定（3-5个核心角色）：
   - 每个角色的名字、身份、性格特征
   - 角色之间的关系和冲突点
   - 每个角色的"记忆点"（让观众一提到就想起来的特征）

3. 分集大纲：
   - 第1-3集（建立期）：铺设矛盾，展示主角的困境
   - 第4-8集（升级期）：矛盾激化，主角开始反击
   - 第9-15集（高潮期）：反转频繁，爽点密集
   - 第16-20集（收官期）：最大反转+结局

4. 每一集的大纲需要包含：
   - 这一集的核心事件（一句话）
   - 本集结尾的钩子（让观众想看下一集的悬念）
   - 本集的情绪曲线（开头是什么情绪→结尾是什么情绪）

5. 特别注意：
   - 第1集的前10秒必须有强钩子，否则观众划走
   - 每3集要有一个小高潮
   - 第10集左右要有全剧最大的反转
   - 结局要让人意犹未尽，有续集的空间
```

**输出模板**（位于 `templates/step2-output.md`）：

| 部分 | 内容 | 字数建议 |
|------|------|---------|
| 一 | 基本信息 | 50字 |
| 二 | 核心设定（4要素） | 200字 |
| 三 | 人物设定（3-5个角色） | 600字 |
| 四 | 分集大纲（20集，每集3要素） | 3000-4000字 |
| 五 | 整体节奏与情绪设计 | 300字 |
| 六 | 续集空间 | 100字 |

**完成后自动引导**：
> ✅ 第二步完成！请告诉我第三步是否继续（撰写第1集完整剧本）。
> 输入 `~step 3` 直接进入第三步。

### 第3步：单集剧本撰写

**目的**：基于第2步的大纲，撰写单集的标准剧本格式。

**标准提示词模板**（位于 `prompts/step3-script.md`）：

```
基于以下故事大纲，请撰写第[X]集的完整剧本。

【故事大纲】[粘贴第2步生成的大纲]
【本集大纲】[填写本集在大纲中的核心事件+钩子+情绪曲线]
【上一集结尾】[如果不是第一集，简要描述上一集最后的场景和悬念]

剧本格式要求：
1. 标准微短剧剧本格式：场景描述 + 人物对话 + 动作指示
2. 总时长控制在90秒左右（大约800-1000字）
3. 前5秒必须有画面冲击或台词钩子，让观众停下来
4. 对话要口语化、短句为主，每句台词不超过15个字
5. 每30秒左右安排一个小冲突或情绪转折点
6. 结尾必须是悬念或反转，切在最吊胃口的地方

情绪节奏要求：
- 本集开场情绪：[填，比如：压抑/愤怒/紧张]
- 本集结束情绪：[填，比如：震惊/解气/心疼]
- 中间要有至少一次情绪反转

额外要求：
- 标注哪些画面需要特写（给拍摄参考）
- 标注背景音乐情绪建议（比如：紧张配乐/舒缓钢琴/燃系音乐）
- 如果有适合做竖屏特效的地方，标注出来
```

**输出模板**（位于 `templates/step3-output.md`）：

| 部分 | 内容 | 字数建议 |
|------|------|---------|
| 一 | 场景1-N（每个含【BGM】+【特写】+画面+台词） | 800-1000字 |
| 二 | 拍摄与制作备注 | 100-200字 |

**完成后自动引导**：
> ✅ 第三步完成！请告诉我第四步是否继续（钩子优化：开头3版本+结尾3版本）。
> 输入 `~step 4` 直接进入第四步。

### 第4步：钩子优化（前5秒+后5秒）

**目的**：为第3步生成的剧本优化开头和结尾，提供3个不同风格的备选方案。

**标准提示词模板**（位于 `prompts/step4-hook.md`）：

```
以下是微短剧第[X]集的剧本。请帮我专门优化两个部分：

【剧本内容】[粘贴第3步生成的单集剧本]

一、开头优化（前5秒）

请给我3个不同版本的开头方案：
- 版本A：悬念型（用一句让人想知道答案的话开场）
- 版本B：冲突型（直接从一个激烈的冲突画面开始）
- 版本C：反常型（用一个违反常理的画面或台词抓住注意力）

每个版本写出具体的画面描述和台词，并说明为什么这个开头能让人停下来。

二、结尾优化（最后5秒）

请给我3个不同版本的结尾钩子：
- 版本A：悬念断点（在最关键的时刻突然结束）
- 版本B：反转炸弹（最后一句话颠覆前面所有剧情）
- 版本C：情感冲击（用一个特写画面+一句台词打动观众的情绪）

每个版本标注：观众看完后最可能在评论区打什么字。
（这是判断钩子好不好的最佳标准——如果观众忍不住评论，就是好钩子）
```

**输出模板**（位于 `templates/step4-output.md`）：

| 部分 | 内容 |
|------|------|
| 一 | 开头优化（3版本 + 评论区预测） |
| 二 | 结尾优化（3版本 + 评论区预测） |
| 三 | 推荐组合（按平台分类） |

**完成后自动引导**：
> ✅ 第四步完成！请告诉我第五步是否继续（自我审查：节奏/人物/商业/审核4维度）。
> 输入 `~step 5` 直接进入第五步。

### 第5步：自我审查

**目的**：作为内容审核编辑，评估剧本是否值得推荐投放。

**标准提示词模板**（位于 `prompts/step5-review.md`）：

```
你现在是一个短剧平台的内容审核编辑，负责评估投稿剧本是否值得推荐。

请审查以下微短剧剧本，从以下角度评估：

【整套剧本】[粘贴全部集数的大纲或剧本]

1. 节奏评估：
   - 每一集的信息密度够不够？有没有"水"的段落？
   - 前3集能不能抓住人？如果不能，问题在哪？
   - 全剧的高潮安排是否合理？有没有中段塌腰（中间几集很无聊）？

2. 人物评估：
   - 主角讨人喜欢吗？观众会不会站主角这边？
   - 反派够不够"可恨"？有没有让人想"快点打他脸"的冲动？
   - 有没有工具人角色？（存在感低、可有可无的角色）

3. 商业评估：
   - 这个故事适合什么平台投放？
   - 预估完播率如何？哪几集是流失高风险集？
   - 有没有适合做"切片引流"的名场面？（可以截出来发短视频吸引人看全剧）

4. 审核风险：
   - 有没有可能触发平台审核的内容？（暴力/擦边/价值观争议）
   - 如果有，给出具体的修改建议

请给出整体评分（满分10分）和最需要优先修改的3个问题。
```

**输出模板**（位于 `templates/step5-output.md`）：

| 部分 | 内容 |
|------|------|
| 一 | 节奏评估（含各阶段评分） |
| 二 | 人物评估（含问题清单） |
| 三 | 商业评估（含平台适配+完播率预测） |
| 四 | 审核风险评估 |
| 五 | 综合评分（4维度+总分） |
| 六 | 优先修改的3个问题 |

**完成后自动引导**：
> ✅ 第五步完成！请告诉我第六步是否继续（AI分镜头脚本撰写）。
> 输入 `~step 6` 直接进入第六步。

## 关键设计原则

### 1. 每步独立可执行
- 每步都有独立的提示词模板，不需要依赖上一步的具体内容
- 用户可以从任意步骤开始（如直接"帮我写个分镜"）

### 2. 标准化的输出格式
- 每步都有明确的输出模板，便于后续AI消费
- 关键信息用表格+清单组织，便于检索

### 3. 平台导向的差异化建议
- 第1步明确推荐赛道
- 第4步针对不同平台（抖音/快手/红果）提供不同的钩子组合
- 第5步评估投放平台适配性

### 4. 审核安全的内嵌设计
- 第5步内置"审核风险评估"环节
- 每步都有红线提醒（如：避免暴力、擦边、价值观争议）

### 5. 配套真实示例
- 完整的《婆婆，您配吗》示例，可作为参考标杆
