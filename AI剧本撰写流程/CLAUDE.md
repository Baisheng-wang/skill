# AI剧本撰写流程 Skill

## 概述

本skill提供从选题到分镜的完整微短剧剧本撰写工作流。包含6个标准化步骤。

## 触发条件

当用户说以下任意内容时，触发本skill：

### 核心触发词
- "AI剧本"、"剧本撰写"、"微短剧创作"、"短剧脚本"、"分镜脚本"
- "帮我写个短剧"、"设计大纲"、"写剧本"、"撰写分镜"
- "选题"、"故事大纲"、"钩子优化"、"自我审查"

### 题材触发词
- "年代逆袭"、"婆媳矛盾"、"霸总甜宠"、"战神归来"、"重生复仇"
- "年代剧"、"重生剧"、"穿越剧"、"甜宠剧"、"爽剧"

### 平台触发词
- "抖音短剧"、"快手短剧"、"红果短剧"、"视频号短剧"

### 步骤触发词
- "第一步"、"第二步"、"第三步"、"第四步"、"第五步"、"第六步"

## 工作流程

```
第1步：选题赛道分析
  ↓
第2步：故事大纲设计
  ↓
第3步：单集剧本撰写
  ↓
第4步：钩子优化（前5秒+后5秒）
  ↓
第5步：自我审查（节奏/人物/商业/审核4维度）
  ↓
第6步：AI分镜头脚本撰写
```

## 文件结构


## 详细规范

### 每步的输入输出

| 步骤 | 输入 | 输出 | 输出文件 |
|------|------|------|---------|
| 1 | 用户提问 | 5大赛道分析 + 推荐 | step1-赛道分析.md |
| 2 | 赛道 + 集数 + 平台 + 受众 | 20集完整大纲 | step2-故事大纲.md |
| 3 | 大纲 + 本集大纲 | 单集标准剧本 | step3-第X集剧本.md |
| 4 | 单集剧本 | 开头3版+结尾3版 | step4-钩子优化.md |
| 5 | 完整大纲/剧本 | 4维度评分 + 修改建议 | step5-审查报告.md |
| 6 | 单集剧本 + 设备 + 风格 | 完整分镜 + 拍摄清单 | step6-第X集分镜.md |

### 输出保存规范

用户产出物应保存到 `outputs/` 目录：

```
outputs/
└── 项目名/
    ├── step1-赛道分析.md
    ├── step2-故事大纲.md
    ├── step3-第X集剧本.md
    ├── step4-钩子优化.md
    ├── step5-审查报告.md
    └── step6-第X集分镜.md
```

## 关键设计原则

### 1. 每步独立可执行
- 每步都有独立的提示词模板
- 用户可以从任意步骤开始

### 2. 标准化的输出格式
- 每步都有明确的输出模板
- 关键信息用表格+清单组织

### 3. 平台导向的差异化建议
- 抖音、快手、红果短剧各有适配版本

### 4. 审核安全内嵌
- 第5步内置"审核风险评估"环节

### 5. 配套真实示例
- 完整《婆婆，您配吗》示例可作为标杆

## 指令集

| 指令 | 说明 |
|------|------|
| `~start` | 从第1步开始 |
| `~step N` | 跳转到第N步（1-6） |
| `~help` | 显示所有可用指令 |
| `~example` | 显示《婆婆，您配吗》完整示例 |
| `~template [N]` | 显示第N步的输出模板 |
