## 分镜专业术语速查表

### 景别类型

| 景别 | 用途 |
|------|------|
| **大特写** | 突出细节（如眼神、手部动作） |
| **特写** | 表现情绪（如面部表情） |
| **近景** | 人物互动 |
| **中景** | 人物+部分环境 |
| **全景** | 交代环境 |
| **远景** | 大场景氛围 |

### 机位/角度

| 角度 | 效果 |
|------|------|
| **仰拍** | 突出主体威严 |
| **俯拍** | 表现渺小/无力 |
| **平视** | 平等、客观 |
| **侧面** | 侧面轮廓 |
| **过肩** | 对话场景 |
| **主观视角** | 代入感 |

### 镜头运动

| 运动 | 用途 |
|------|------|
| **固定** | 静态、稳定 |
| **推进** | 强调、靠近 |
| **拉远** | 揭示、退场 |
| **摇移** | 跟随动作 |
| **手持** | 紧张、纪实 |
| **航拍** | 大场景 |
| **慢镜头** | 情绪放大 |

### 转场方式

| 转场 | 适用场景 |
|------|---------|
| **硬切** | 节奏紧凑 |
| **溶暗** | 时间流逝 |
| **叠化** | 回忆/梦境 |
| **特效转场** | 穿越/特殊效果 |
| **切光** | 强烈情绪转折 |
| **匹配剪辑** | 动作连贯 |
