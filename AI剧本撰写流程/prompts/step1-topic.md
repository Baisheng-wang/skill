# 第1步：选题赛道 - 详细提示词

## 标准提示词

```
你是一个资深的微短剧策划，在抖音和快手做了3年短剧内容，经手过多部播放量破亿的项目。
请帮我分析当前微短剧市场最热门的5个赛道。

要求：
1. 每个赛道给出：
   - 赛道名称和核心吸引力（为什么观众爱看）
   - 典型爆款案例1-2个（剧名+大致剧情）
   - 目标受众画像（性别、年龄、看剧场景）
   - 当前竞争程度（红海/蓝海/中等）
   - 适合新手入场的程度（1-5分）

2. 在5个赛道中，推荐1个最适合新手的赛道，理由要具体

3. 补充说明：当前平台（抖音/快手/红果短剧）各自偏好什么类型的内容？审核红线在哪？
```

## 输出模板

```markdown
# 微短剧赛道分析报告

## 一、当前最热门的5大赛道

### 赛道1：[赛道名]
**核心吸引力**：[为什么观众爱看，2-3句话]
**典型爆款案例**：
- [剧名]：[剧情简述]
- [剧名]：[剧情简述]
**目标受众画像**：
- 性别：[男X%/女Y%]
- 年龄：[XX-XX岁]
- 场景：[观看场景描述]
**竞争程度**：[红海/蓝海/中等]
**新手适合度**：⭐⭐（X分）

### 赛道2-5（结构同上）

## 二、新手推荐赛道：[赛道名]
**推荐理由**：
1. [理由1]
2. [理由2]
3. [理由3]
4. [理由4]
5. [理由5]

## 三、各平台偏好与审核红线

### 抖音
- **偏好**：[内容偏好]
- **流量逻辑**：[流量分发逻辑]

### 快手
- **偏好**：[内容偏好]
- **流量逻辑**：[流量分发逻辑]

### 红果短剧
- **偏好**：[内容偏好]
- **策略**：[平台策略]

### 审核红线（共通）
1. **绝对禁止**：[内容]
2. **价值观导向**：[内容]
3. **不能出现**：[内容]
4. **软红线**：[内容]
5. **平台特异**：[内容]
```

## 执行检查清单

- [ ] 输出5个赛道分析（每个含5要素）
- [ ] 推荐1个最适合新手的赛道（理由具体）
- [ ] 覆盖抖音/快手/红果短剧3大平台
- [ ] 明确审核红线（绝对禁止+软红线）
- [ ] 总字数控制在2500-3500字
- [ ] 输出完成后引导用户进入第2步
