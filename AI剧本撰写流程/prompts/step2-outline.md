# 第2步：故事大纲 - 详细提示词

## 标准提示词

```
我要做一部微短剧，基本信息如下：

【赛道】[填你选的赛道，比如：都市情感逆袭]
【集数】[填总集数，比如：20集，每集1-2分钟]
【目标平台】[填平台，比如：抖音短剧]
【目标受众】[填受众，比如：25-40岁女性，下班后刷剧解压]

请帮我设计一个完整的故事大纲，要求：

1. 核心设定：
   - 一句话概括这个故事（不超过30字）
   - 主角是谁？TA的初始处境是什么？（要够惨或够不甘）
   - 核心反转是什么？（从什么变成什么）
   - 爽点在哪里？（观众看到什么时候会觉得"过瘾"）

2. 人物设定（3-5个核心角色）：
   - 每个角色的名字、身份、性格特征
   - 角色之间的关系和冲突点
   - 每个角色的"记忆点"（让观众一提到就想起来的特征）

3. 分集大纲：
   - 第1-3集（建立期）：铺设矛盾，展示主角的困境
   - 第4-8集（升级期）：矛盾激化，主角开始反击
   - 第9-15集（高潮期）：反转频繁，爽点密集
   - 第16-20集（收官期）：最大反转+结局

4. 每一集的大纲需要包含：
   - 这一集的核心事件（一句话）
   - 本集结尾的钩子（让观众想看下一集的悬念）
   - 本集的情绪曲线（开头是什么情绪→结尾是什么情绪）

5. 特别注意：
   - 第1集的前10秒必须有强钩子，否则观众划走
   - 每3集要有一个小高潮
   - 第10集左右要有全剧最大的反转
   - 结局要让人意犹未尽，有续集的空间
   也可以根据自己想要的提示词进行修改
```
