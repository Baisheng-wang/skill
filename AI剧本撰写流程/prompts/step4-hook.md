# 第4步：钩子优化 - 详细提示词

## 标准提示词

```
以下是微短剧第[X]集的剧本。请帮我专门优化两个部分：

【剧本内容】[粘贴整集剧本]

一、开头优化（前5秒）

请给我3个不同版本的开头方案：
- 版本A：悬念型（用一句让人想知道答案的话开场）
- 版本B：冲突型（直接从一个激烈的冲突画面开始）
- 版本C：反常型（用一个违反常理的画面或台词抓住注意力）

每个版本写出具体的画面描述和台词，并说明为什么这个开头能让人停下来。

二、结尾优化（最后5秒）

请给我3个不同版本的结尾钩子：
- 版本A：悬念断点（在最关键的时刻突然结束）
- 版本B：反转炸弹（最后一句话颠覆前面所有剧情）
- 版本C：情感冲击（用一个特写画面+一句台词打动观众的情绪）

每个版本标注：观众看完后最可能在评论区打什么字。
（这是判断钩子好不好的最佳标准——如果观众忍不住评论，就是好钩子）
```

## 钩子设计原则

### 开头（前5秒）三大类型

| 类型 | 核心逻辑 | 适用题材 |
|------|---------|---------|
| **悬念型** | 用一句话/画面引发"为什么" | 重生/悬疑/推理 |
| **冲突型** | 3秒内建立强冲突画面 | 婆媳/战神/职场 |
| **反常型** | 违反常理的画面抓住注意力 | 年代/穿越/反差 |

### 结尾（后5秒）三大类型

| 类型 | 核心逻辑 | 适用题材 |
|------|---------|---------|
| **悬念断点** | 在最关键时刻突然结束 | 推理/重生/复仇 |
| **反转炸弹** | 最后一句颠覆前面剧情 | 战神/霸总/年代 |
| **情感冲击** | 特写+台词打动观众 | 婆媳/亲子/爱情 |

### 评论区预测原则

好的钩子能引发以下类型的评论：

| 类型 | 示例 |
|------|------|
| **情绪代入型** | "我靠 太过分了" |
| **疑问追问型** | "这是什么意思？" |
| **观点表态型** | "男/女主人设绝了" |
| **共鸣分享型** | "这不就是我吗" |
| **剧透警告型** | "我看到结局了 别告诉别人" |
