# 第3步：单集剧本 - 详细提示词

## 标准提示词

```
基于以下故事大纲，请撰写第[X]集的完整剧本。

【故事大纲】依据上述生成的故事大纲
【本集大纲】[第一集大纲]
【上一集结尾】[如果不是第一集，简要描述上一集最后的场景和悬念]

剧本格式要求：
1. 标准微短剧剧本格式：场景描述 + 人物对话 + 动作指示
2. 总时长控制在90秒左右（大约800-1000字）
3. 前5秒必须有画面冲击或台词钩子，让观众停下来
4. 对话要口语化、短句为主，每句台词不超过15个字
5. 每30秒左右安排一个小冲突或情绪转折点
6. 结尾必须是悬念或反转，切在最吊胃口的地方

情绪节奏要求：
- 本集开场情绪：[填，比如：压抑/愤怒/紧张]
- 本集结束情绪：[填，比如：震惊/解气/心疼]
- 中间要有至少一次情绪反转

额外要求：
- 标注哪些画面需要特写（给拍摄参考）
- 标注背景音乐情绪建议（比如：紧张配乐/舒缓钢琴/燃系音乐）
- 如果有适合做竖屏特效的地方，标注出来
```

## 标准剧本元素清单

### BGM情绪建议参考

| 情绪 | BGM风格 | 适用场景 |
|------|---------|---------|
| 压抑 | 低沉弦乐、汉斯季默风格 | 开场压迫感 |
| 紧张 | 鼓点+快节奏 | 冲突场景 |
| 绝望 | 大提琴独奏、慢节奏 | 情绪低谷 |
| 震惊 | 全静音+心跳声 | 反转瞬间 |
| 怀旧 | 90年代怀旧BGM | 年代穿越 |
| 燃 | Two Steps From Hell - Victory | 决心/觉醒 |

### 竖屏特效常用类型

| 特效类型 | 适用场景 |
|---------|---------|
| 人物泛冷光 | 情绪爆发点 |
| 全屏白光 | 穿越/觉醒瞬间 |
| 慢镜头 | 关键动作/情绪 |
| 字幕特效 | 关键信息呈现 |
| 定格+慢推 | 结尾钩子 |

### 拍摄标注参考

- **【特写】**：面部表情、手部动作、关键物件
- **【中景】**：人物互动场景
- **【全景】**：环境交代
- **【航拍竖屏】**：大场景
- **【慢镜头】**：情绪放大
