# 第5步：自我审查 - 详细提示词

## 标准提示词

```
你现在是一个短剧平台的内容审核编辑，负责评估投稿剧本是否值得推荐。

请审查以下微短剧剧本，从以下角度评估：

【整套剧本】[粘贴全部集数的大纲或剧本]

1. 节奏评估：
   - 每一集的信息密度够不够？有没有"水"的段落？
   - 前3集能不能抓住人？如果不能，问题在哪？
   - 全剧的高潮安排是否合理？有没有中段塌腰（中间几集很无聊）？

2. 人物评估：
   - 主角讨人喜欢吗？观众会不会站主角这边？
   - 反派够不够"可恨"？有没有让人想"快点打他脸"的冲动？
   - 有没有工具人角色？（存在感低、可有可无的角色）

3. 商业评估：
   - 这个故事适合什么平台投放？
   - 预估完播率如何？哪几集是流失高风险集？
   - 有没有适合做"切片引流"的名场面？（可以截出来发短视频吸引人看全剧）

4. 审核风险：
   - 有没有可能触发平台审核的内容？（暴力/擦边/价值观争议）
   - 如果有，给出具体的修改建议

请给出整体评分（满分10分）和最需要优先修改的3个问题。
```

## 评分标准参考

### 节奏评估（10分制）

| 分数 | 评价 |
|------|------|
| 9-10分 | 节奏紧凑，全程无水分 |
| 7-8分 | 节奏良好，有少量可优化空间 |
| 5-6分 | 节奏一般，有明显的"水段" |
| < 5分 | 节奏混乱，需重写 |

### 人物评估（10分制）

| 分数 | 评价 |
|------|------|
| 9-10分 | 主角立体，反派可恨，配角有记忆点 |
| 7-8分 | 主角较立体，反派合格 |
| 5-6分 | 主角扁平，反派脸谱化 |
| < 5分 | 工具人严重，需重塑 |

### 商业评估（10分制）

| 分数 | 评价 |
|------|------|
| 9-10分 | 商业潜力大，多平台适配 |
| 7-8分 | 商业潜力良好，1-2个平台优选 |
| 5-6分 | 商业潜力一般，需优化 |
| < 5分 | 商业化困难 |

### 审核风险（10分制）

| 分数 | 评价 |
|------|------|
| 9-10分 | 无审核风险 |
| 7-8分 | 小风险，可控 |
| 5-6分 | 中风险，需修改 |
| < 5分 | 高风险，需重大修改 |
